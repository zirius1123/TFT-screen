# TFT Screen
I made a basic TFT screen for half life. It uses a basic 2.8" 240×320 SPI TFT with touch and a Rasberry Pi Pico. It also has 6 Cherry MX keys and one bourns slider pot.
## In depth description of components.
I am using kicad software and am using the 2.8" 240×320 SPI TFT with touch for the screen, which consists of the
* ILI9341 screen chip
* XPT2046 touch chip
I am also using
* A rasberry pi pico 2
* 6 Cherry MX
* 1 Bourns Slider pot
I also used 2 capacitors and 2 transistors
